5. OOP: Classes, Methods & Encapsulation

OOPConstructors 
public class Account {
    // Encapsulation: Private instance variables
    private String id;
    private double balance;

    // Static member belongs to class, shared across all instances
    private static int totalAccounts = 0;

    // Constructor with 'this' resolving variable shadowing
    public Account(String id, double balance) {
        this.id = id;
        this.balance = balance;
        totalAccounts++;
    }

    // Overloaded Constructor
    public Account(String id) {
        this(id, 0.0);         // Invokes constructor above
    }

    // Getters & Setters
    public double getBalance() { return this.balance; }
    public static int getTotalAccounts() { return totalAccounts; }

    // Varargs parameter (must be the final parameter)
    public void recordTransactions(String note, double... amounts) {
        for (double a : amounts) {
            this.balance += a;
        }
    }
}
Memory & Reference Passing: Java is strictly call-by-value. When passing an object reference to a method, a copy of the reference address is passed. Manipulating internal attributes alters the shared object, but reassigning the reference variable itself does not affect the caller's pointer.

Class Inheritance & Polymorphic Dispatch

abstract class Shape {
    abstract double area();    // Abstract method: no body
}

interface Drawable {
    void draw();
    // Default method (JDK 8+)
    default void renderDetails() {
        System.out.println("Standard vector rendering");
    }
}

class Circle extends Shape implements Drawable {
    private double radius;
    public Circle(double radius) { this.radius = radius; }

    @Override
    double area() { return Math.PI * radius * radius; }

    @Override
    public void draw() { System.out.println("Drawing circle"); }
}

// Usage: Superclass reference bound to subclass object
Shape s = new Circle(5.0);
System.out.println(s.area()); // Dynamic method dispatch

8. Exception Architecture & Resources

Exceptions 
// Try-with-resources: automatically invokes close() on AutoCloseable items
try (java.io.FileReader fr = new java.io.FileReader("file.txt");
     java.util.Scanner sc = new java.util.Scanner(fr)) {
    while (sc.hasNextLine()) {
        System.out.println(sc.nextLine());
    }
} catch (java.io.FileNotFoundException e) {
    System.err.println("File not found: " + e.getMessage());
} catch (java.io.IOException | NumberFormatException e) {
    // Multi-catch (JDK 7+)
    System.err.println("I/O or parsing error: " + e.getMessage());
} finally {
    // Always runs regardless of exception
}

9. Collections Framework & Maps

java.utilGenerics
ArrayList vs LinkedList

ArrayList gives $O(1)$ random access, slow insertions in the middle. LinkedList allows fast insertions/deletions at ends, $O(n)$ access.

HashSet vs TreeSet

HashSet offers unsorted, unique items via hash table. TreeSet maintains Red-Black tree sorted order ($O(\log n)$ operations).

import java.util.*;

// 1. List Operations
List<String> list = new ArrayList<>();
list.add("Alpha");
list.add("Beta");
list.remove(0);

// 2. Set Operations (deduplication)
Set<Integer> set = new HashSet<>();
set.add(10);
set.add(10); // Ignored

// 3. Map Operations (Key-Value pairs)
Map<String, Integer> map = new HashMap<>();
map.put("Mark", 100);
map.put("Alice", 95);

for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}

Synchronization & Inter-thread Communication

class Counter {
    private int count = 0;
    // Synchronized method locks 'this' object monitor
    public synchronized void increment() {
        count++;
    }

    // Synchronized block
    public void reset() {
        synchronized(this) {
            count = 0;
        }
    }
}

11. I/O: Streams, Readers & File Operations

java.io
Byte Streams

InputStream / OutputStream, FileInputStream. Reads raw 8-bit bytes (binaries, images).

Character Streams

Reader / Writer, BufferedReader. Handles 16-bit Unicode text translations automatically.

import java.io.*;

// Efficient buffered file reading
File file = new File("data.txt");
if (file.exists()) {
    try (BufferedReader reader = new BufferedReader(new FileReader(file))) {
        String line;
        while ((line = reader.readLine()) != null) {
            System.out.println(line);
        }
    }
}

// File Writing
try (BufferedWriter writer = new BufferedWriter(new FileWriter("out.txt"))) {
    writer.write("Persisting offline text data");
    writer.newLine();
}

12. Graphical UI: Swing & AWT Reference

GUISwing 
import javax.swing.*;
import java.awt.*;
import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;

public class BasicGuiApp {
    public static void main(String[] args) {
        // Swing GUI operations must run on Event Dispatch Thread
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("App Window");
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            frame.setSize(400, 200);
            frame.setLayout(new BorderLayout());

            JTextField textField = new JTextField();
            JButton button = new JButton("Submit");
            JLabel label = new JLabel("Status: Waiting");

            // Event Handling
            button.addActionListener(new ActionListener() {
                @Override
                public void actionPerformed(ActionEvent e) {
                    label.setText("Entered: " + textField.getText());
                }
            });

            frame.add(textField, BorderLayout.NORTH);
            frame.add(button, BorderLayout.CENTER);
            frame.add(label, BorderLayout.SOUTH);

            frame.setVisible(true);
        });
    }
}

Common Layout Managers

  • FlowLayout: Places components left-to-right in natural size; wraps to new rows.
  • BorderLayout: 5 designated zones: NORTH, SOUTH, EAST, WEST, CENTER.
  • GridLayout: Arranges components into an equal-dimension matrix grid (rows, columns).
